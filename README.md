# Shadow Emulator

A simple browser-based emulator page built with [js-dos](https://js-dos.com/).

## Features
- Drag-and-drop `.exe` support
- File picker fallback
- In-browser DOSBox screen for gameplay

## Important
This app can run **DOS-compatible** executables. Modern Windows `.exe` files are not compatible with in-browser DOSBox.

## Run locally
Use any static server, for example:

```bash
python3 -m http.server 8080
```

Then open `http://localhost:8080`.
